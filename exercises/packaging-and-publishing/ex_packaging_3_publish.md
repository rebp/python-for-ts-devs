# Exercise 11.3-3: Rehearse a release

In a scratch package, identify the metadata, build backend and console script
entry point. Write the commands to build a wheel and source distribution, then
publish to TestPyPI. Do not actually upload anything for this exercise.

Hint: `uv build` writes to `dist/`; TestPyPI has a separate upload URL.

This one is checked by you, not by a test. When you're done, run:

```bash
uv run course.py --done
```

The reference answer is in `solutions/packaging-and-publishing/ex_packaging_3_publish.md`.
