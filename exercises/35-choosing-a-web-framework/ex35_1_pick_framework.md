# Exercise 35-1: Pick a framework

For each project, pick FastAPI, Django or Flask and write one sentence on why.

1. A JSON API that a React front end calls. The front-end team wants typed
   request and response models and up-to-date API docs.
2. An internal tool with a database, user logins and screens where
   non-developers edit records.
3. Two new endpoints in a service your team already runs, written in Flask
   five years ago.

There's no single right answer, so compare your reasoning with the reference
answer rather than just the framework names.

This one is checked by you, not by a test. When you're done, run:

```bash
uv run course.py --done
```

The reference answer is in `solutions/35-choosing-a-web-framework/ex35_1_pick_framework.md`.
