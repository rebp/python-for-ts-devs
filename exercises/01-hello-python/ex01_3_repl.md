# Exercise 01-3: Explore the REPL

Open the Python REPL, Python's version of typing `node` in a terminal:

```bash
uv run python
```

Evaluate these three expressions and write down what each one does:

```python
2 ** 10
7 / 2
7 // 2
```

Bonus: try `-7 // 2`. Is it the same as `Math.trunc(-7 / 2)` in JavaScript?

Leave the REPL with `exit()`.

This one is checked by you, not by a test. When you're done, run:

```bash
uv run course.py --done
```
